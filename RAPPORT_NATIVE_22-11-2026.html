2 Installation sur Android / tablette Android

  1. Transférez le .apk sur le téléphone (câble USB, AirDrop, Drive, WhatsApp, e-mail).
  2. Ouvrez le fichier depuis le gestionnaire de fichiers.
  3. Autorisez « Sources inconnues » quand Android le demande.
  4. Installez — l'icône violette avec l'alpha rouge apparaît sur l'écran d'accueil.

Par câble : adb install -r ~/Documents/Metanoia-App/METANOIA-Android.apk

3 iPhone / iPad — PWA installable sans store 🍎

Serveur HTTPS local (Wi-Fi de l'église)

  • Lancez serveur-https.command (double-clic) sur le Mac.
  • Certificat local généré avec mkcert pour 10.10.10.166, localhost et 127.0.0.1 (valable jusqu'en février 2029).
  • Le serveur écoute sur https://10.10.10.166:8443 — testé : l'app et l'APK répondent en 200.
  • Le service worker met l'application en cache : une fois installée, elle fonctionne hors ligne, même Mac éteint.

Procédure sur l'iPhone / l'iPad

  1. Connectez l'appareil au même Wi-Fi que le Mac.
  2. Ouvrez Safari et allez sur https://10.10.10.166:8443.
  3. Avertissement de certificat → « Avancé » → « Accepter le risque » (certificat local de l'église).
  4. Bouton Partager → « Sur l'écran d'accueil ».
  5. L'icône METANOÏA apparaît, ouverture plein écran, fonctionnement hors ligne.

L'installation du profil de certificat (fichier CA dans certificats/) rend l'acceptation permanente sur chaque appareil.
